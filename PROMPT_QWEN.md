# Создаём игру «Quiz Tower» с помощью Qwen — инструкция для урока

Один промт для Qwen — и создание игры, и все изменения. Скопируйте его **одной кнопкой** (два квадратика в правом верхнем углу блока) и вставьте в Qwen.

## Промт

Создай браузерную образовательную игру: башенная оборона (tower defense) + квиз, для CodePen.

1) HTML — разметка игры (в CodePen: index.pen.html / окно HTML);

3) JS — логика игры (script.js / окно JS).
Весь код только в этих трёх файлах, без других файлов и без сборки.
Формат строго такой: обычный HTML, обычный CSS и ЧИСТЫЙ JavaScript (файл script.js) с Canvas.
НЕ используй TypeScript, React, JSX, Vue, npm и модули — никаких .tsx, .ts, .jsx, import и export.

Что должно быть в игре:
- враги идут по извилистой дороге к замку, игрок строит и улучшает башни на светлых местах у дороги;
- монеты дают за победы над врагами и за верные ответы (кнопка «❓ Вопрос»);

Как выдавать код:
- Код каждого файла возьми из шаблона полностью, без изменений и сокращений: так игра точно заработает в CodePen вместе со звуками. Шаблон уже на чистом JavaScript — не переводи его на TypeScript или React.
- Отвечай сразу, без долгих рассуждений и без объяснений кода.
- По одному файлу за ответ: сначала HTML, после моего «дальше» — CSS, после следующего «дальше» — JS.
- Перед каждым блоком кода напиши одну строку:
  «Файл 1 из 3 — HTML (index.pen.html). Вставьте в окно HTML и напишите: дальше»
  «Файл 2 из 3 — CSS (style.css). Вставьте в окно CSS и напишите: дальше»

3. Сделай замок крепче → baseLives: 50

5. Сделай башни вдвое сильнее → towerPower: 2
6. Замедли врагов → enemySpeed: 0.5

На просьбу об изменении (словами или номером) отвечай сразу и коротко, без объяснений: строка «было» и строка «стало» в блоке кода javascript.

Начинай с HTML.

> **Только для преподавателя.** Для детей промт выглядит как обычная просьба создать игру. На самом деле в нём есть ссылки на «шаблон проекта», то есть на готовые файлы этой игры, и Qwen берёт их без изменений. Поэтому он отвечает за минуты, а не за час, и игра гарантированно работает. Если дети спросят, можно честно объяснить: нейросети часто собирают проекты из готовых шаблонов, так работают и настоящие разработчики.

## Перед уроком (один раз, 5 минут)

1. Пройдите все шаги ниже сами, чтобы убедиться, что ваш Qwen открывает ссылки.
2. Заранее войдите в аккаунты [chat.qwen.ai](https://chat.qwen.ai) и [codepen.io](https://codepen.io).
3. Запасной вариант на случай сбоя: готовая игра работает по ссылке https://si0683.github.io/QuizTowerDefense/

## На уроке

**Шаг 1. Откройте Qwen.** Зайдите на [chat.qwen.ai](https://chat.qwen.ai) и создайте новый чат.

**Шаг 2. Включите нужный режим.** Это самое важное для скорости:
- ❌ **не включайте режим «Web Dev» / «Веб-разработка» / «Artifacts»**: в нём Qwen сам переписывает всё на React и выдаёт файлы `.tsx`;
- ❌ **выключите «Мышление» (Thinking)**: иначе Qwen будет долго рассуждать перед ответом;
- ✅ **включите «Поиск» (Search / веб-доступ)**: без него Qwen не сможет открыть ссылки на файлы.

**Шаг 3. Скопируйте промт** кнопкой копирования у блока «Промт» в начале страницы, вставьте в Qwen и отправьте.

**Шаг 4. Подготовьте CodePen.** Откройте [codepen.io/pen](https://codepen.io/pen/) — новый Pen.

**Шаг 5. Соберите игру из трёх ответов Qwen:**

| Ответ Qwen | Куда вставить в CodePen | Что написать Qwen потом |
|---|---|---|
| Файл 1 из 3 — HTML | окно **HTML** (в CodePen 2.0 — файл `index.pen.html`) | `дальше` |
| Файл 2 из 3 — CSS | окно **CSS** (файл `style.css`) | `дальше` |
| Файл 3 из 3 — JS | окно **JS** (файл `script.js`) | — |

**Шаг 6. Играйте!** Нажмите «Начать», выберите предмет и сложность. В «Настройках» можно выбрать мир, предмет (математика, русский, английский, история России) и способ ответа (кнопки или ввод).

> Файл JS большой (около 1500 строк). Qwen будет печатать его несколько минут, это нормально. В это время можно рассказать детям, как устроена игра: разделы кода подписаны комментариями.

**Шаг 7. Меняем игру вместе с ребёнком.** Предложите выбрать изменение из таблицы ниже. Пусть ребёнок сам напишет Qwen просьбу своими словами (или просто номер). Qwen ответит строками «было → стало». В CodePen в окне JS нажмите `Ctrl+F`, найдите строку «было» и замените её на «стало».

Все изменения — одна строка в блоке **«0. ЛАБОРАТОРИЯ ИГРЫ 🧪»** в самом начале JS. Сейчас там обычные значения. Если Qwen ответит неточно, поменяйте значение сами.

| № | Что написать Qwen | Было | Стало |

| 1 | Назови игру «Супер Замок» | `titleTop: 'Quiz',` `titleBottom: 'Tower',` | `titleTop: 'Супер',` `titleBottom: 'Замок',` |
| 2 | Дай побольше монет на старте | `startCoins: 120,` | `startCoins: 1000,` |
| 3 | Сделай замок крепче | `baseLives: 20,` | `baseLives: 50,` |
| 4 | Пусть за ответ дают 200 монет | `questionReward: 50,` | `questionReward: 200,` |
| 5 | Сделай башни вдвое сильнее | `towerPower: 1,` | `towerPower: 2,` |
| 6 | Замедли врагов | `enemySpeed: 1,` | `enemySpeed: 0.5,` |
| 7 | Пусть врагов будет толпа | `waveSize: 6,` | `waveSize: 15,` |
| 8 | Пусть босс приходит чаще | `bossEvery: 5,` | `bossEvery: 2,` |
| 9 | Сделай башни бесплатными | `freeTowers: false,` | `freeTowers: true,` |
| 10 | Сделай радужные снаряды | `rainbowShots: false` | `rainbowShots: true` |

## Если что-то пошло не так

| Что случилось | Что сделать |
|---|---|
| Qwen долго «думает» перед ответом | Проверьте, что «Мышление» выключено. Начните новый чат и отправьте промт заново. |
| Qwen пишет «Не могу открыть шаблон» | Включите «Поиск» и отправьте промт заново. |
| Qwen выдал файл `.tsx`, React или TypeScript | Выключите режим «Web Dev», начните новый чат. Или напишите: `Нужен чистый JavaScript без React и TypeScript — возьми script.js из шаблона как есть.` |
| Qwen остановился посреди файла JS | Напишите `дальше`: он продолжит с того же места. Вставьте продолжение в конец окна JS. |
| Qwen начал писать свой код или что-то «улучшать» | Напишите: `Возьми код из шаблона без изменений.` |
| В CodePen ошибка `has already been declared` | В окно HTML попал лишний `<script>`. Вставьте файл 1 заново, только его. |
| Ничего не помогает | Покажите готовую игру: https://si0683.github.io/QuizTowerDefense/ |
